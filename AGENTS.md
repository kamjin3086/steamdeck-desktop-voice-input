# Agent entry points

When asked to install, repair, or verify this application on a user's machine, read [docs/AGENT_INSTALL.md](docs/AGENT_INSTALL.md) or its [Chinese translation](docs/zh-CN/AGENT_INSTALL.md), and follow its completion checks.

For code changes, read [docs/DEVELOPING.md](docs/DEVELOPING.md). Keep user-facing text, code comments, and test descriptions in English. Maintain English documentation and its Simplified Chinese companion pages; add reciprocal language links. Multilingual speech fixtures use Unicode escapes so their original language remains testable.

Preserve existing user configuration and button bindings. Keep downloaded models, virtual environments, credentials, recordings, and transcript logs outside version control. Device permissions and Desktop Mode are runtime requirements, not conditions to bypass with system-wide changes.
