# Roadmap

The current release targets SteamOS Desktop Mode. Planned work is subject to testing and contributor interest:

- Validate more SteamOS versions and controller layouts on physical Deck hardware.
- Improve device-disconnection recovery and microphone selection.
- Add model/language selection directly in the GUI.
- Expand model integrity metadata and model-specific compatibility checks.
- Improve coverage for different clipboard/paste targets and accessibility workflows.

Gaming Mode support would require separate input, focus, window, and injection validation. It is not part of the supported feature set.
